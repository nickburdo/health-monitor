**Цель:** Добавить тёмную тему для всего интерфейса и переключатель «светлая / тёмная» в шапке.

**Архитектура:** Используется модуль `@nuxtjs/color-mode`, который уже входит в Nuxt UI v4 и включён по умолчанию (в `nuxt.config.ts` нет `ui.colorMode: false`). Модуль ставит класс `dark` на `<html>` и сохраняет выбор пользователя в localStorage. Все цвета интерфейса берутся из CSS-переменных в `app/assets/css/main.css`; тёмная тема переопределяет их в блоке `:root.dark`.

**Технологии:** Nuxt 4 (только клиент), Nuxt UI v4 (`useColorMode`, `UIcon`), CSS-переменные. Новых зависимостей нет.

## Решения пользователя

- **Два режима:** светлая и тёмная. При первом запуске тема берётся из ОС (`preference = 'system'`), после клика по переключателю сохраняется выбор пользователя.
- **Палитра тёмной темы:** «тёплый графит» с оранжевым акцентом.
- **Ветка:** `feature/dark-theme` от актуального `main`.

## Открытые предложения (одобрены вместе с планом)

1. **Свой компонент `ThemeToggle.vue` вместо `UColorModeButton`.** Шапка написана на собственных классах `.health-*`, а `UColorModeButton` оформлен в стиле Nuxt UI (neutral/ghost) и будет выбиваться. Компонент использует `useColorMode()` и `UIcon` (`i-lucide-sun` / `i-lucide-moon`). Клик выставляет `colorMode.preference` в противоположное от текущего `colorMode.value`.
2. **Тёмная тема — один блок `:root.dark { ... }`.** Жёстко заданные цвета (`white`, `rgba(...)`) выносятся в новые токены. В светлой теме у токенов те же значения, что сейчас, поэтому она визуально не меняется.
3. **Цвета серий графиков — через CSS-переменные.** В `app/utils/health-line-chart/*.ts` hex заменяется на строки `var(--chart-…)`. В `HealthLineChart.vue` цвета серий применяются через `:style`, а не через SVG-атрибуты `stroke` / `fill`, чтобы `var()` гарантированно работал.
4. **`app/app.config.ts` не меняется.** Расхождение `primary: 'green'` с оранжевым акцентом не связано с этой задачей.
