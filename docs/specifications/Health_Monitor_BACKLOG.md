## Технический долг

### Выборка списков по индексу дат

Сейчас `list*` в `app/lib/db/repositories/*Repository.ts` читают всю таблицу (`toArray()`), а затем фильтруют по `dateFrom` / `dateTo` и сортируют в памяти. Индексы `measuredAt` / `happenedAt` в `app/lib/db/schema.ts` при этом не используются.

Сделать:

- выбирать диапазон дат и сортировку по индексу средствами Dexie, без чтения всей таблицы;
- вынести дублированную функцию `withinRange` и тип `DateRangeQuery` (сейчас объявлен в `glucoseRepository.ts`) в общий модуль.

Приоритет низкий: для личного объёма данных (тысячи записей) разница незаметна. Перед реализацией — план и сверка API Dexie с документацией.

### Общий список таблиц данных

Список четырёх таблиц данных повторяется в `dataTables()` (`app/lib/db/seed.ts`) и вручную в `exportHealthMonitorData` / `importHealthMonitorData` (`app/lib/db/export-import.ts`). При добавлении новой сущности легко забыть одно из мест, и очистка или импорт оставят в ней старые строки.

Сделать:

- вынести список таблиц данных в `app/lib/db/schema.ts` и использовать его в seed, export и import.

### Место для операций над всей базой

`clearHealthMonitorData` лежит в `seed.ts`, хотя это общая операция над базой, а логика «очистить все таблицы» продублирована в транзакции импорта в `export-import.ts`.

Сделать:

- собрать операции над всей базой (очистка, замена) в одном модуле и переиспользовать в импорте.

### Обновление схемы при открытых старых вкладках

При переходе на новую версию схемы Dexie (`this.version(n)`) вкладка со старым бандлом получает `versionchange`, соединение закрывается, и следующее обращение к БД падает без понятного сообщения; новая вкладка может ждать `blocked`.

Сделать:

- сверить поведение Dexie по документации и при необходимости обработать `versionchange` / `blocked` (например, toast с предложением перезагрузить страницу).

### Старт приложения при ошибке загрузки демо-данных

`app/plugins/seed-demo-data.client.ts` ждёт `seedDemoDataIfEmpty()`. Если при первом запуске `$fetch('/data/demo.json')` падает (нет сети, 404 на превью), плагин отклоняется и приложение не стартует, пока сеть не вернётся. Так было и до кнопок демо-данных.

Сделать:

- ловить ошибку загрузки демо-данных, стартовать с пустой базой и показывать toast.
