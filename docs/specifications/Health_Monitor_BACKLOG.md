## Улучшения интерфейса

Идеи для будущей полировки:

- drag-and-drop порядка карточек;
- настройка видимости карточек;
- compact mode;
- print-friendly reports;
- улучшенные empty states;
- onboarding;
- подсказки по первому запуску;
- меню страниц в шапке: при открытии ставить фокус на пункт текущей страницы, а не на первый (сейчас поведение `UDropdownMenu` по умолчанию);
- карточки-ссылки дашборда: короткое доступное имя (`aria-label`, например «Open glucose page»): сейчас скринридер читает всё содержимое карточки;
- шапка на экране 640 и менее: `.health-header-inner` использует `width: calc(100vw - 16px)`, а `100vw` включает ширину обычной (не накладной) полосы прокрутки, поэтому на десктопном браузере в узком окне логотип прижат к левому краю; на телефонах с накладной прокруткой не проявляется;
- удержание фокуса (focus trap) во всех модальных окнах (`ConfirmDialog`, quick entry, диалог игнорирования, произвольный период): сейчас Tab уводит фокус на элементы страницы за фоном, и с клавиатуры можно, например, нажать другую кнопку дашборда при открытом диалоге подтверждения.

## Скиллы

### `deploy-check` — разбор сборок Cloudflare Pages

Сейчас при зависшей или упавшей сборке всё выясняется вручную. Скилл должен:

- показывать статус сборки Cloudflare Pages для коммита или PR через `gh api repos/<owner>/<repo>/commits/<sha>/check-runs` и сравнивать его с предыдущими сборками;
- проверять githubstatus.com (вебхуки, Actions) и cloudflarestatus.com (компонент Pages);
- подсказывать, какие сборки в очереди отменить (превью смерженных веток, устаревшие сборки `main`), а какую перезапустить (последний коммит `main`);
- просить лог из дашборда, если сборка упала, и различать ошибку клонирования и ошибку `npm run generate`.

## Аккаунт

Не сделано при переходе на Platform API (план: `docs/plans/platform-api-auth-plan.md`):

- привязка Google к аккаунту с паролем (`POST /auth/google/link`, nonce обязателен);
- установка пароля Google-аккаунту (`POST /auth/me/password`), с предупреждением про невосстановимый пароль;
- вход через Google на превью веток Cloudflare Pages: расширить allowlist в `platform-api`.
