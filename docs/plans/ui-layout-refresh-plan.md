**Цель:** освободить место в шапке под будущие Sign-in и переключатель языка, сделать карточки дашборда ссылками на страницы сущностей, починить подписи единиц на карточках и графики (линия не заходит на подписи оси, текст не сплющивается на узких карточках).

**Архитектура:**

- **Шапка** (`HealthShell.vue`): пять ссылок `.health-nav` заменяются одним выпадающим меню. Кнопка-триггер показывает иконку и название текущей страницы и шеврон; список — все пять страниц с иконками, текущая отмечена. Мобильный футер (`.health-footer`, ≤ 640px) не меняется; на ≤ 640px триггер скрыт так же, как сейчас скрыт `.health-nav`. Справа остаются `ThemeToggle` и «+ Add entry», места хватает для будущих кнопок.
- **Карточки** (`HealthMetricCard.vue`): новый необязательный проп `to`; если он задан, корень карточки — `NuxtLink` вместо `article`. `DashboardMetricsGrid.vue` передаёт `/glucose`, `/blood-pressure`, `/weight`, `/symptoms`.
- **Шрифт единиц:** `.health-unit` наследует `letter-spacing: -0.06em` от `.health-value`, поэтому буквы `mmol/L`, `kg`, `entries` наезжают друг на друга. Задать `.health-unit` свой `letter-spacing: normal`.
- **График** (`HealthLineChart.vue`), исправляется свой, без библиотеки:
  - причина сплющивания: SVG с фиксированным `viewBox="0 0 1000 288"` и `preserveAspectRatio="none"` растягивается по ширине контейнера вместе с текстом и точками (точки становятся эллипсами);
  - причина наезда: подписи оси Y рисуются в `x = 10`, а линия и сетка начинаются в `x = 5`, отступа под подписи нет;
  - решение: измерять реальную ширину и высоту области графика (`ResizeObserver`), строить `viewBox` в реальных пикселях без `preserveAspectRatio="none"`; слева отвести колонку под подписи оси (ширина по самой длинной подписи), подписи выравнивать по правому краю колонки (`text-anchor="end"`), сетку и линии рисовать правее неё.

**Технологии:** Nuxt UI v4 `UDropdownMenu` (уже в зависимостях), `ResizeObserver` (браузерный API). Новых зависимостей нет.

## Решения пользователя

- **Меню в шапке:** выпадающее меню вместо ряда ссылок; мобильный футер остаётся.
- **Карточки дашборда:** ссылки на соответствующие страницы.
- **Графики:** исправить свой `HealthLineChart`, библиотеку не подключать.
- **Разбиение работы:** вторая задача после `fix/glucose-mmol-units`.
- **Ветка:** `feat/ui-layout-refresh` от актуального `main` (отдельный worktree `../health-monitor-ui-refresh`); перед началом кода ветка перебазируется на `main` после слияния PR #23 (исправление глюкозы).

## Принятые предложения

1. **`UDropdownMenu` вместо самописного дропдауна.** По документации Nuxt UI v4 элементы `items` принимают `label`, `icon` и любые props `Link` (`to`), есть флаг `active`; триггер — свой слот (наша кнопка в стиле `.health-*`), стили выпадающего списка задаются через проп `ui` нашими классами с `var(--…)`. Это даёт клавиатурную навигацию, закрытие по Escape и клику снаружи без своего кода. Альтернатива — свой компонент (кнопка + список + обработка клавиатуры), больше кода.
2. **Ширина колонки подписей оси** считается приблизительно: `длина самой длинной подписи × 7px + 8px` (шрифт 12px, цифры). Без измерения текста через `getBBox`, чтобы не было лишнего перерендера.
3. **Высота графика** остаётся из CSS (288px, 240px на ≤ 640px); `ResizeObserver` берёт её из размера элемента, так что `viewBox` всегда совпадает с размером на экране.
4. **Наведение на карточку-ссылку:** тот же эффект, что у ссылок в навигации (`translateY(-1px)`) и видимый фокус с клавиатуры; без смены цвета карточки.

## Пересмотр плана 2026-11-09 (по итогам finish-task, одобрен пользователем)

Отступления реализации, принятые задним числом:

- **Задача 3:** текущий пункт меню выделяется классом `is-active` через свойство `class` элемента, а не флагом `active`; иконки пунктов получают класс через `ui.itemLeadingIcon`. Фон и тень меню — отдельные токены (задача 7) вместо `--surface`.
- **Задача 4:** `ResizeObserver` подключается в `watch` на ref SVG с `onCleanup`, а не в `onMounted` / `onBeforeUnmount`: SVG рендерится только при наличии данных (`v-if`), и `onMounted` его бы пропустил.

Исправления по код-ревью и проверке в браузере — задача 7.

- Кнопка Sign-in и переключатель языка (только место под них).
- Подписи единиц на оси графика и подписи дат по оси X — остаются как есть.
- Изменения мобильного футера.
