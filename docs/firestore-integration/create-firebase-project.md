# Create Firebase project
- открыть Firebase Console.
- нажать Add project / Create project.
- ввести Project name
- Google Analytics можно выключить.
- нажать Create project.
- после создания открыть проект.

# Register Web App
- нажать Add app.
- выбрать </> (Web).
- ввести App nickname
- `Also set up Firebase Hosting` ПОКА НЕ ЧЕКАТЬ
- нажать Register app.
