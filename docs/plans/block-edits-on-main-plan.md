**Цель:** Claude Code не может править файлы проекта, пока текущая ветка — `main`: правка блокируется с подсказкой создать ветку через start-task.

**Архитектура:** хук `PreToolUse` на инструменты `Edit|Write|NotebookEdit`, зарегистрированный в `.claude/settings.json` проекта; логика — в скрипте `.claude/hooks/block-edits-on-main.mjs` на Node (одинаково работает на Windows и в Git Bash). Код приложения не меняется.

**Технологии:** Node (уже установлен), git. Новых зависимостей нет.

## Решения пользователя

- **Область:** все файлы внутри папки проекта; файлы вне проекта (память, scratchpad, `~/.claude`) не трогаются.
- **Реакция:** блокировать правку (код выхода 2), а не спрашивать.
- **Регистрация:** `.claude/settings.json` проекта, коммитится вместе со скриптом.
- **Ошибка внутри хука** (нет git, битый JSON): правка пропускается, в stderr пишется предупреждение.
- **Файлы из `.gitignore`** (`.claude/settings.local.json`, `.nuxt/`, `.playwright-mcp/`): разрешено править и на `main`, проверка через `git check-ignore`.
- **Обход для срочной правки на `main`:** попросить Claude временно отключить хук и включить обратно после правки; отдельного «рубильника» в скрипте нет.
- **Хранение плана:** chore-план сохранён в файл по просьбе пользователя, без пунктов в `next-update.md` и `Health_Monitor_plan.md`.
- **Ветка:** `chore/block-edits-on-main` от актуального `main` (создана 2026-10-22).

## Что не покрыто

- Правки через Bash (`sed`, heredoc, `cp`): хук видит только `Edit|Write|NotebookEdit`.
- `git commit` на `main`: возможное отдельное улучшение.
- Правки самого пользователя в редакторе: хук действует только на Claude.
