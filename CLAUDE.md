# Health Monitor

A personal web app for tracking health: glucose, blood pressure, weight, and symptoms. Quick entry, tables, charts, a period filter, and an `ignore` flag for invalid measurements.

## Working rules

- Write user questions and work reports in Russian.

## Commands

- `npm run dev`: dev server on port `3030`
- `npm run lint`, `npm run typecheck`: the same checks CI runs (`.github/workflows/ci.yml`)
- `npm run build`: build check; `npm run generate`: static build for hosting
- `npm run demo:generate`: regenerate `public/data/demo.json`

## Architecture

- Nuxt 4 + Nuxt UI v4 + Tailwind 4, client-only (`ssr: false`). No server and no auth.
- Data lives in the browser's IndexedDB via Dexie.js: schema and repositories in `app/lib/db/` (`schema.ts`, `repositories/*Repository.ts`); JSON and CSV export/import live there too.
- `prisma/schema.prisma` only documents the data shape; it is not connected to any database.
- With an empty database, the app seeds itself from `public/data/demo.json` (generated by `scripts/generate-demo-data.mjs`).
- Charts use the hand-written SVG component `HealthLineChart`; series and formatters are in `app/utils/health-line-chart/`.
- Symptoms are a static list in `app/constants/symptom-options.ts`.

## Styles and themes

- Styling uses custom `.health-*` classes in `app/assets/css/main.css`; Nuxt UI components are barely used.
- All colors go through CSS tokens defined in `:root`; the dark theme overrides them in `:root.dark`. Do not write colors (`white`, hex, `rgba`) directly in component styles; add a token with values for both themes instead.
- The theme is switched by `@nuxtjs/color-mode` (bundled with Nuxt UI) via the `dark` class on `<html>`; the toggle is `app/components/ThemeToggle.vue`.
